# Архитектура Exchange Rate Bot

Проект следует правилу зависимостей Clean Architecture: зависимости исходного
кода направлены от внешних слоёв к внутренним. Домен и сценарии приложения не
знают о Fastify, Telegram, Frankfurter, Vercel или переменных окружения.

## Слои

```text
src/
├── domain/          чистая предметная логика
├── application/     сценарии и порты внешних зависимостей
│   └── ports/       контракты, реализуемые адаптерами
├── presentation/    HTTP-сервер и преобразование входящих запросов
├── infrastructure/  реализации портов для внешних API
└── main/            composition root и запуск приложения
```

- `domain` не импортирует другие слои.
- `application` может импортировать только `domain` и собственные порты.
- `presentation` вызывает сценарии `application`.
- `infrastructure` реализует порты, объявленные в `application`.
- `main` — единственное место, где создаются и связываются конкретные классы
  всех слоёв.

При добавлении нового API, транспорта или базы данных контракт следует помещать
в `application/ports`, а его реализацию — в `infrastructure`. Новая точка входа
должна находиться в `presentation`, а её подключение — в `main`.
